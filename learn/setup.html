设置私人访问码

访问码只在你的浏览器里随机生成，不会自动上传，也不会写入网址或浏览器存储。

先保存到自己的密码管理器中，之后用它登录网站。不要发送到聊天或截图中。

打开 Cloudflare → 这个 Worker → Settings → Variables and Secrets，添加 Secret，名称为 OWNER_ACCESS_HASH，值为上面的摘要，然后保存并部署。原始访问码不要填进去。

配置完成，去登录

这页不会设置服务器密码。只有填入 Worker Secret 的摘要所对应的访问码才能登录。关闭页面后，未保存的访问码无法恢复；重新生成不会自动改变当前登录码。
